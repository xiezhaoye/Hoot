# Hoot（原 ShotPad）功能说明

> 给改界面的 AI / 开发者看的：这份文档描述 **当前版本（v0.2.1 持续编辑与智能截图版本）已经实现的全部功能**，包括看不见的行为、快捷键、数据存储和不能破坏的约定。改 UI 时请保持这些行为不变，除非用户明确要求改。
>
> 代码目录：`~/project/hoot`。应用显示名叫 **Hoot**，但为了不丢数据，**bundle id（`com.xiezhaoye.shotpad`）、数据目录（`ShotPad/`）、钥匙串服务名（`ShotPad.LLM`）、SwiftPM 目标名（`ShotPad`）都没有改名**，不要改。

## 1. 产品定位

macOS 原生（Swift）的截图 / 标注 / 看图工具，类似 PicPick。后续计划继续加：录屏、视频剪辑、本地图传。吉祥物是一只猫头鹰（图标已做，`Resources/AppIcon.icns`）。

- 平台：macOS 15+，Apple Silicon，Swift 5 语言模式，SwiftPM（tools 6.0）。
- 技术：AppKit + SwiftUI 混合；ScreenCaptureKit 截屏；Vision 做 OCR；Translation 框架做本地翻译；Carbon 注册全局热键；ImageIO 读写图片。
- 应用是 **常驻菜单栏**的（状态栏图标），同时可以在 Dock 显示（设置项，默认显示）。

## 3. 数据模型要点（改 UI 时容易踩的约定）

- **坐标**：文档内一律是 **图像像素、左上角为原点**。画布到屏幕的换算用 `CanvasView.zoom`（点/像素）。100% 缩放 = 1 个图像像素对应 1 个屏幕物理像素（Retina 下 `zoom = 0.5`）。界面上显示的百分比 = `zoom × backingScaleFactor × 100`。
- **文档（EditorDocument）**：`底图 + 标注列表 + 多个区块(Patch) + 对象层序`，快照式撤销（`State{base, annotations, patches, order}`）。
  - 标注绘制完成后是**矢量对象**，可在当前选框内反复移动、缩放、改样式；点击选框外部或切换工具后自动固定进底图。
  - **浮动块**：粘贴进来的图、或从选区"抬起"的区域。有 8 个缩放手柄；点击外部、切换工具或再次粘贴时固定。抬起选区时，原位置被**白色**填充。
  - 自动固定、“固定全部”（⇧⌘F）或“保存”（⌘S）把全部区块和标注合并进底图，合并可用 ⌘Z 撤销；如果区块超出画布，**画布自动向外扩展（白色）**。
- **画布外边距**：`CanvasView.inset = 240pt`，图像四周留空，方便把浮动块停在图外。
- **画板（Board）**：从截图快捷条点“编辑”时，截图放到一块 **固定尺寸的白色画板左上角**（默认 1920×1080 像素，设置可改；截图更大则自动撑大）。从历史栏重新打开某张图、或从“浏览”送去编辑的图，**不套画板**，保持原图尺寸。
- **颜色**：`RGBA` 是 sRGB。`AppSettings.noteUsed(_:)` 维护“最近使用的 10 个颜色”（最新在前，近似色去重）。

## 4. 全局入口

### 4.1 全局快捷键（Carbon，系统范围）

| 快捷键 | 作用 |
|---|---|
| **⌃⌥A**（默认，可在设置里改） | 截图 |
| **⌃⌥P**（固定） | 把剪贴板里的图片钉住（置顶悬浮） |

截图快捷键的设置：设置窗口里点按钮 → 按下新组合（至少带一个 ⌃⌥⇧⌘ 修饰键）→ 立即重新注册，同时更新菜单栏菜单里的显示。**没有检查与系统快捷键的冲突**。

### 4.2 菜单栏状态图标（viewfinder）

菜单项：截图（显示当前快捷键）、钉住剪贴板 ⌃⌥P、打开最近一张、历史保留数量（子菜单，选项数量，默认 50）、设置…、退出。

### 4.3 应用主菜单（屏幕顶部）

- Hoot：截图、设置…（⌘,）、退出 Hoot（⌘Q）。
- 编辑：剪切、复制、粘贴、全选、撤销、重做等标准项，通过响应者链作用到画布（画布实现了 `cut:` `copy:` `paste:`）。

### 4.4 Dock 与激活策略

- 设置“始终在 Dock 显示”（默认开）：开 → 一直是 `.regular`（有 Dock 图标和主菜单栏）；关 → 只有编辑窗口或设置窗口打开时才临时变 `.regular`，否则 `.accessory`（LSUIElement 效果）。由 `AppDelegate.refreshPolicy()` 统一决定，窗口打开/关闭时都会调用。
- 点 Dock 图标且没有可见窗口时（`applicationShouldHandleReopen`）：`openMain()`。
- 关闭最后一个窗口**不退出应用**。

### 4.5 启动行为

启动后立即 `openMain()`：打开**最近一张历史截图**的编辑窗口；没有历史则打开一块 **1200×800 的空白白板**。同时在后台做 **OCR 预热**（`TextTools.warmUp()`，启动前十几秒会有一点 CPU 和内存上升，之后空闲）。若没有屏幕录制权限，启动时会向系统请求。

## 5. 截图流程

1. 触发（快捷键 / 菜单 / 工具栏左侧的圆形“截图”按钮，三者效果完全一致）。
2. `ScreenCapture.captureAll()` 对**每块显示器**各抓一张冻结图（不排除任何窗口，所以钉住的图片和 Hoot 自己的窗口也会拍进去）。
3. `CaptureOverlay` 在每块屏幕上盖一个全屏窗口（窗口层级 = 屏蔽层级），显示冻结图 + 40% 黑色蒙层：
   - **拖动**框选区域；**点击**则选中鼠标悬停的控件 / 面板 / 窗口（`ScreenCapture.windows()` 提供，包含 Hoot 自身、浮动面板及弹窗，排除不可见窗口）。
   - 选区内显示原亮度，边框用设置里的“选区颜色”，旁边显示 `宽×高` 像素。
   - **十字定位线**：贯穿整块屏幕的横竖两条细线，随鼠标移动，颜色同选区颜色。
   - **放大镜**：8 倍，15×15 像素格，带网格和中心十字，附坐标和选区尺寸；跟随鼠标，靠近屏幕边缘时自动避让。
   - **Esc 取消**（既有视图内的 keyDown，也有一个本地事件监听兜底，保证遮罩出现期间 Esc 一定生效）；**右键也取消**。
4. 松开鼠标 → 裁出像素图，立即：
   - 写入历史（见第 9 节，生成真实文件）；
   - 若设置“截图后自动复制到剪贴板”已开，则同时写剪贴板；
   - 弹出 **快捷操作条**（见下）。

### 5.1 快捷操作条（QuickBar）

- **原位预览**：刚截的图原样显示在它被截取的屏幕位置（`OverlayView`），**操作条贴在它下方**。
- 按钮：**文字**（识别并复制）、**URL**（打开网址 / 二维码链接）、**翻译**、**编辑**、**复制**（原图）、**分享**（按默认模板复制图片）、**钉住**、**✕**。
- 文字、URL、翻译、编辑、复制和钉住操作成功后，操作条和预览关闭；分享成功后继续保留浮层。文字复制成功时播放系统 “Tink” 提示音，失败 `beep`。
- **分享**：下拉菜单提供“原图（原尺寸）”与“适配手机”。原图保留截图内容尺寸，按默认模板的背景、颜色、留白、圆角和阴影生成 PNG 并复制；不增加 OCR 等待，不打开系统分享菜单。
- 两种分享结果均直接显示在原截图浮层内，保持蓝色虚线框选中及工具栏，可继续移动、标注、输入文字、选择局部、粘贴和撤销。后续操作使用当前编辑结果；再次选择“原图”直接复制当前结果，不重复叠加背景。
- 长图自动适应屏幕；⌘滚轮、触控板捏合或 ⌘+/⌘− 调整预览大小，普通滚轮移动预览，⌘0 恢复适应屏幕。拖动外框八个控制点等比例调整预览；预览缩放不会改变输出图片的像素尺寸。
- **适配手机**：用本地 Vision OCR 提取文字，按行距、首行缩进、标题和列表恢复段落，将段内自动折行合并，再排成固定 1080 像素宽的纯文字图片。高度随内容和模板留白自动增减，短内容生成紧凑卡片；保留一行正文及上下文字边距的最小高度。正文使用 48 像素字号，不为缩短图片缩小字号或摘要删减；沿用默认模板装饰。图片、表格和代码版式暂不重建。
- 手机模式在后台分块识别长图，分块带重叠与归属范围以避免边界丢行或重复；识别、整理段落、生成图片均显示进度。处理时锁定截图编辑；“取消”或 Esc 返回当前截图，关闭按钮取消任务并退出。成功后更新原浮层并复制，失败或取消不改变剪贴板。最近三张图的识别结果按实际像素缓存在内存中，调整截图会重新识别，更换模板则复用文字并重新渲染。
- “编辑”：打开编辑窗口，并把截图放到固定尺寸画板左上角。
- **浮层编辑**：选区内部拖动即抬起并移动内容，四角调整选框，边中点拉伸内容；区块可反复移动、缩放和复制粘贴，移动范围限制在截图区域内。已选中的图形可从虚线框内部拖动，控制点显示相应鼠标样式。点击标注外部或切换工具后固定，⌘Z 可撤销固定。
- 浮层工具栏提供剪切、复制、粘贴入口及各工具独立样式；文字支持多行输入、字体和字号选择、拖动边框、四角缩放字号和左右调整换行宽度。右键保留取消选区 / 截图的行为。

## 6. 编辑窗口

### 6.1 总体布局

```
┌───────────────────┬───────────────────────────────────────────┬──────────────┐
│ 侧栏 224pt         │  自定义标题栏 70pt（红黄绿 + Hoot + 截图 + │ 检查器 228pt │
│ [截图|浏览]         │   撤销/重做/保存/识别/翻译）                │（默认展开）   │
│                   ├───────────────────────────────────────────┤              │
│ 新建画板 / 搜索框   │  标注栏 46pt（12 个工具 + 缩放百分比）      │ 颜色/描边/   │
│ 历史缩略图（按天）  ├───────────────────────────────────────────┤ 填充/圆角/   │
│                   │  画布（浏览标签时被“浏览预览”覆盖）          │ 阴影/尺寸    │
│                   ├───────────────────────────────────────────┤              │
│                   │  状态栏 36pt（尺寸/格式/缩放快捷键）        │              │
└───────────────────┴───────────────────────────────────────────┴──────────────┘
```

尺寸是**当前实现值**，统一定义在 `EditorChrome.swift` 的 `EditorStyle`：`sidebarWidth = 224`、`inspectorWidth = 228`、`footerHeight = 36`；标题栏 70、标注栏 46 写在 `EditorView.swift`。改布局时改这些常量，不要在视图里散写数字。

- **标题栏与下方栏的垂直分隔线必须上下对齐**：标题栏右组用「侧栏所在那一侧的宽度」（历史栏在右时 224，在左时 228），底栏统一 `footerHeight`。这是被反复修过的对齐问题。
- 历史栏在**右侧**时使用 224pt，在**左侧**时右侧让给检查器 228pt。
- `Hoot` 标题是 22 点半粗文字（不带 logo）；左上是原生红黄绿按钮占 88×70 的空间。
- 窄窗口（宽度 < 1180）时「识别文字 / 翻译」只留图标不显示文字；标注栏用 `ViewThatFits` 把低频工具收进 `⋯` 菜单。
- 左/右侧位置由设置“历史栏位置”决定（**默认右**）。切到“浏览”标签时，画布只是隐藏，**选区、浮动块、撤销栈都保留**。

### 6.2 标题栏（70pt，自绘，不是 NSToolbar）

左侧：原生红黄绿按钮（88×70 空间）+ `Hoot` 文字。右侧按标签页分成两组：

- **「截图」标签**：
  - 左内组：`截图` 按钮（camera.viewfinder 图标 + 文字，38pt 高）→ 与工具栏左侧圆形截图按钮、全局快捷键**完全等价**；中间是可拖窗的空白（`EditorWindowDragArea`）；窄于此处的动作按钮按优先级压缩。
  - `撤销 ⌘Z` / `重做 ⇧⌘Z` → 分隔线 → `识别文字` / `访问 URL` / `翻译` + 方向下拉；最右侧为 `复制图像`、`保存图片`、检查器开关。固定按钮位于检查器中。
- **「浏览」标签**：右侧换成蓝色 `编辑图片` 主按钮（把当前预览图送去编辑；无选中时禁用）。
- 检查器开关贴在最右边缘，与左侧按钮之间用弹性间隔分开。

**注意**：顶部**没有**「导出」主按钮（2026-10-25 移除）；保存靠 ⌘S 与标题栏的 `保存`。画布的 ⌘S 打开保存面板，取消即不固定。

### 6.3 标注栏（46pt，第二行）

- 12 个工具：手形（无工具）、选区、矩形、圆圈、直线、箭头、画笔、荧光笔、文字（图标是衬线体 “A”）、序号、马赛克、模糊、裁剪。
- **选中态**：选中的按钮是蓝底白图标；**再点一次同一工具 = 取消选中**，回到“手形（无工具）”状态。
- **无工具状态（`Tool.hand`，软件刚打开就是这个）**：鼠标是小手，拖动画面可平移。此时浮动块仍可拖动/缩放。
- 窗口宽度不足时 `ViewThatFits` 把 `直线 / 荧光笔 / 序号 / 模糊` 收进 `⋯` 菜单（不是直接隐藏）。
- 最右：缩放百分比文字菜单（`适合窗口` + 25/50/100/150/200/400/800%）。

### 6.4 检查器（228pt，右侧，可收起）

启动时默认展开，选择工具时自动展开；标题栏的 `sidebar.right` 图标可临时收起。按选中对象类型分节显示：

- **颜色**：常用色常驻 + 最近使用的 10 色圆点 + 完整取色器 + 吸管。
- **描边**：线宽（用一条 Capsule 预览实际粗细）。
- **填充**：三种（无填充 / 半透明 / 实心）。
- **不透明度**、**圆角**（含 0/4/8/12/16/24/32/48 预设）、**阴影**开关。
- **尺寸与位置**：W/H/X/Y 输入框 + 比例锁 + 排列（置顶 / 置底）。
- **字体**：文字工具可选择本机已安装的字体，记住上次选择；字体随标注保存进草稿。
- **固定**：所有工具的检查器提供固定按钮；无未固定对象时禁用。快捷键 ⇧⌘F 保留。
- **图片背景**（选区 / 裁剪）：预览当前区域，可选无背景、纯色、渐变、自定义本地背景图片；背景留白 0～256 px、内容圆角 0～64 px、阴影均可调整。图片背景等比例铺满并居中裁切。设置自动记住，图片复制进应用数据目录后不依赖原文件。
- **模板**：首次使用将原背景设置迁移为“默认模板”，并提供“清爽蓝”“纸白”预设。可切换模板、保存修改、另存为新模板、重命名、设为默认或删除；至少保留一个模板，删除前备份到废纸篓。
- 切换模板只改变当前面板效果，浮层分享使用标为“默认”的已保存模板。“设为默认”会一并保存当前调整；另存新模板不会自动改变默认模板。未保存的参数会标记“已修改”。面板同时显示浮层分享正在使用的模板名称。
- 模板库位于 `~/Library/Application Support/ShotPad/ImageTemplates.plist`，每个图片背景模板包含自己的 PNG，不会被其他模板更换背景时覆盖。编辑中的参数、模板选择和背景也会配套记住，支持多个编辑窗口。
- 预览下方提供 **复制图片 / 保存图片**，输出带背景的区域 PNG；不打开系统分享菜单，不修改画布或裁剪范围。普通 ⌘C 仍复制区域原图。
- 无选中对象时只显示默认样式（供下一次绘制使用）。
- **改颜色/线宽/字号/填充/不透明度/圆角/阴影会同时作用到当前选中的标注**，且不取消选中、不固定对象。

### 6.5 状态栏（36pt，底栏）

左侧：图像尺寸 `宽 × 高 像素` + 当前文件格式；右侧：当前工具提示或「区块可持续编辑 / 删除区块」，再右是 **50% / 100% / 150%** 快捷缩放（当前档高亮）。底栏横线与侧栏、检查器的底部分隔线**必须齐平**（统一 `footerHeight = 36`）。

### 6.6 画布交互（CanvasView）

**平移与缩放**
- 无工具时拖动平移；两指滑动是系统滚动。
- **触控板捏合缩放**，以手指位置为锚点；范围 5%–800%（按物理像素计）。
- ⌘= / ⌘+ 放大，⌘- 缩小，⌘0 回到 100%。
- 撤销/重做**不重置缩放和滚动位置**（以前会重置，已修）；打开别的历史图时重置为 100%。

**选区工具**
- 拖出选区（虚线框 + 8 个手柄）；光标是十字，并有贯穿画面的十字定位线 + 放大镜。
- 原始选区：拖动边线或内部移动框选范围，拖四角调整范围。只改变复制范围，不抬起、不缩放底图像素。
- 复制后粘贴得到独立区块；拖动内部移动，拖边或角缩放。剪切 / Delete 用白色遮罩清空选区，不固定其他对象。
- **移动/缩放浮动块时画出“两横两竖”的定位线**（沿块的上下左右四条边，贯穿画面，颜色同选区色），方便对齐，松手消失。
- ⌘A 全选，⌘C 复制选区，**⌘X 剪切**（复制后原位变白），⌘V 粘贴。

**浮动块**
- 粘贴的图：**落在鼠标位置**（鼠标在画布外则放中心）；过大则按比例缩小以适应画布；允许落到图外。
- 可移动、可用 8 个手柄拉伸、**方向键微调（Shift = 10 像素）**。
- 无需回车确认；点击外部、换工具、再次粘贴会固定当前对象。Esc 取消区块选中；Delete 删除选中区块，可撤销。

**绘图工具**
- 矩形、圆、直线、箭头：拖动绘制，绘制完自动选中。蓝色虚线包围框内任意位置都可移动；单击内部和反复拖动保持选中，移出后仅悬停不会固定，点击外部或切换工具才固定。
- **控制点与再编辑**：八个边角控制点显示对应方向的缩放光标；直线和箭头的两端显示可拖动光标。内部显示手形，拖动时为抓手。同类绘图工具可选回撤销固定后恢复的对应图形；“移动 / 选区”可选择各类可编辑标注。连续修改样式不会固定或取消选中。
- 画笔、荧光笔：自由绘制，可再选中、移动、缩放、改样式。马赛克、模糊：拖框，作用在框内像素。序号：默认直径 64px，自动递增；调整大小、颜色后，新序号继承当前格式。
- 裁剪：点击图标立即按全部可见内容的最小外接矩形生成裁剪框（排除外围白色画布；空白画布回退为整张画布）。八个控制点可调整范围，内部可移动。检查器设置四边预留 0～100 px，默认 0，自动记住；预留超出原画布时补白。回车确认裁剪并复制结果，⌘Z 可撤销裁剪。离开裁剪工具会清除裁剪框。

**文字工具**
- 点击创建原生多行文字编辑框，初始最小宽度 40 图像像素；输入时自动横向增长，不把初始宽度当成用户设定的宽度。
- 编辑中通过外边框或顶部“拖动文字框”区域移动，即使内容为空也能移动；框内拖动用于选择文字。非编辑时拖动交互区域移动；双击进入编辑。
- 四角显示缩放光标，拖动时保持对角位置并同步缩放字号；左右中点改变文本框宽度，调窄后自动换行，不改变字号。字体、字号、颜色、不透明度可在输入过程中实时调整；点击检查器不结束编辑。
- **回车 = 换行**（⇧回车同样换行）。未手动设宽时随文字增长；手动设宽后在该宽度内换行。原生编辑器与 PNG 渲染使用同一字体和换行宽度。
- 点击画布其他位置或切换工具结束并固定文字；空白文字在结束输入时丢弃。

**Delete / 退格键**（优先级）：选中的标注 → 浮动块 → 选区（该区域变白）→ 裁剪框。

**Esc**：固定当前选中的标注，或取消区块选中（不删除）；同时清选区和裁剪框。

**右键菜单**：剪切 / 复制 / 粘贴。

**光标规则**：无工具 = 小手；其余工具 = 十字；在原始选区四角 / 粘贴区块边角上 = 缩放光标；选区/浮动块内部 = 小手。

## 7. 识字与翻译

- **OCR 只用本地 Vision**（`.accurate`、语言：简中、繁中、英文、自动检测），不使用大模型 OCR。
- 对象：有选区时用选区，否则用整张图（含浮动块，但不烘焙）。
- **识别文字**：弹出小结果窗（320×190）显示文字，可复制，结果同时写入剪贴板的文字部分。
- **翻译**：**大模型优先，本地兜底**。
  - 配置了 Base URL + API Key + 模型名（三项都填）才启用 LLM，走 OpenAI 兼容的 chat completions，要求返回 JSON 数组（逐行对应）；失败或未配置则回退到系统 `Translation` 框架。
  - 方向：自动（按识别文字是否主要为中文判断）/ 中文 / 英文。
  - 结果在小窗里显示，Key 存在钥匙串（服务名 `ShotPad.LLM`）。
- 设置里有“测试连接”按钮（翻译 “Hello”）。

## 8. 钉住（PinWindow）

- 置顶悬浮的无边框窗口，显示一张图，默认出现在鼠标位置。
- 拖动移动；滚轮缩放（10%–800%）；双击或 Esc 关闭；右键菜单：复制、透明度 100/70/40%、关闭。
- **不会因为切换到别的应用而被隐藏**（`hidesOnDeactivate = false`），所以钉住后再截图，它仍然在最前面。
- 来源：快捷条“钉住”、⌃⌥P（钉剪贴板）、菜单栏“钉住剪贴板”。

## 9. 截图历史与文件存储

- **每次截图、每次点“新建”、每次从“浏览”送去编辑**，都会在保存目录下**生成一个真实的图片文件**，同时成为一条历史记录。
- **默认保存目录**：`~/Library/Application Support/ShotPad/History`（里面还有一个 `index.json`，记录顺序、尺寸、日期、文件名）。可在设置里更换（更换时把现有文件**复制**过去，**重启后生效**）。
- **文件名**：`截图 2026-10-25 15.30.12.png`；新建的空白画板叫 `画板 …`；浏览送去编辑的叫 `图片 …`；同一秒重名自动加 ` 2`、` 3`。旧版本留下的 `<UUID>.png` 仍可读取。
- **格式**：设置里选，支持 PNG（默认）、JPG、HEIC、TIFF、BMP、GIF、JPEG 2000。**WebP macOS 只能读不能写，所以不提供**。不支持透明的格式（JPG/BMP/GIF/JPEG 2000）会先垫白底。
- 编辑后的预览**写回同一个历史文件**。切换条目或关闭窗口时同时写入独立编辑草稿，重新打开可继续编辑，不隐式固定。
- ⌘S 第一次选择 PNG 文件路径，之后写回该路径；仅写入成功后统一固定全部标注和区块。取消或写入失败保留可编辑对象。固定可撤销，但磁盘文件须再次保存才会改变。
- 完整草稿存 `~/Library/Application Support/ShotPad/Drafts/`，版本化二进制 plist 包含无损底图、区块、对象 ID、层序、文字内容与样式、撤销/重做。重启恢复所有未关闭的画板窗口。
- 保留数量默认 50（菜单栏可改），超出自动删除最旧的**文件**。从历史栏右键“删除”会同时删除对应文件。
- 历史栏缩略图缓存在内存里，条目变化时失效。
- 历史**不再分类**（以前有“正常/提取文字/翻译”三类，已合并成“截图”；旧记录里的 `group` 字段仍会被解码但不再使用）。

### 9.1 侧栏“截图”标签

- 顶部是**分段控件** `[截图 | 浏览]`（36pt 高、圆角、选中项带轻投影），不是两个独立按钮。
- 接着是 `新建画板` 大按钮（42pt 高、通栏白底灰边）：创建一块**空白白色画板**（尺寸取设置值），生成文件并打开。**这里没有截图按钮**——截图在标题栏。
- 然后是搜索框（29pt 高，可按名称 / 短名 / 日期 / 尺寸模糊匹配）。
- 再下面是**按天分组**的缩略图列表（今天 / 昨天 / 月日），每组标题右侧显示张数；条目是最新在前，点击打开；右键“删除”。当前打开的高亮（蓝边 + 浅蓝底 + 显示尺寸与格式）。
- 侧栏底部：左侧 `N 张截图`（浏览标签时显示 `N 个分组`），右侧齿轮进设置。

## 10. “浏览”标签

### 10.1 侧栏

- **分组 → 文件夹** 两级结构（一个文件夹只属于一个分组）。数据存 `~/Library/Application Support/ShotPad/browse.json`（只存路径，不复制图片）。
- 分组：新建（底部“新建分组”，立刻进入重命名）、重命名（右键）、删除分组（右键）、折叠/展开（点击分组行）。
- 文件夹：分组行右侧的按钮或右键“添加文件夹…”（多选）；也可以把 **Finder 里的文件夹拖到分组上**；右键“在 Finder 中显示”“从分组移除”。
- 文件夹被删或移动后显示警告图标并置灰，悬停提示路径。
- **只看当前一层**，不包含子文件夹；监听目录变化（`DispatchSource`），Finder 里增删图片会自动刷新列表。

### 10.2 右侧预览

- 支持格式：png、jpg、jpeg、heic、heif、gif（只显示首帧）、webp、tif、tiff、bmp。排序：按文件名，自然排序（b2 在 b10 前）。
- 底色 **白色**。底栏（36pt，与其他底栏齐平）显示 `第几张 / 共几张`。**「编辑图片」按钮在窗口右上角（标题栏里），不在预览底栏**。
- **翻页区**：大图**左右各半个区域**都是翻页点击区（不是只在箭头附近点），中间是图片本身；箭头的视觉尺寸保持较小（42×54 胶囊，距边 18）。到头的方向箭头透明度降到 0.25 且点击无效（`page(delta)` 不循环）。双击翻页区 = 送去编辑。
- 图片加载：ImageIO 缩略图 API，**应用 EXIF 方向**，大图降采样到 3200 像素；带 400 项的内存缓存。
- **键盘（只在浏览标签、有选中文件夹时生效）**：

| 按键 | 大图模式 | 网格模式 |
|---|---|---|
| ← → | 上一张 / 下一张（到头不循环） | 移动高亮 |
| ↑ | 进入缩略图网格 | 上移一行 |
| ↓ | — | 下移一行；已在最后一行则回到大图 |
| 回车 | 把当前图送去编辑 | 回到大图 |
| Esc | — | 回到大图 |
| 空格 | 切换到网格 | 切换回大图 |

- 双击大图 = 送去编辑；双击缩略图 = 回大图查看它；单击缩略图 = 高亮。
- **送去编辑**：读取全分辨率原图，作为一条新的“截图”历史（文件名前缀“图片”），切回“截图”标签并打开；**不修改原文件**，也不套画板。
- 实现细节：用一个 `KeyCatcher`（NSView）保持第一响应者来接收按键；输入框（重命名分组）正在编辑时不抢焦点。若方向键没反应，点一下右侧预览区。

## 11. 设置窗口（Hoot 设置）

左侧菜单 158pt（**通用 / 识字与翻译 / 关于与更新** 三类，均 22pt 图标容器 + 42pt 行高 + 18pt 最大图形，选中项浅蓝底、`focusEffectDisabled`），右侧 `Form` 独立滚动。每次打开都按**当前画板窗口**所在屏幕居中并限制在可见区域内；没有画板时按鼠标所在显示器居中。

**通用**

- 截图：截图快捷键（录制器）、保存格式。
- 截图：`截图后自动复制到剪贴板`、`智能识别窗口内部模块`（附带「授权辅助功能…」按钮）、`截图圆角` + 像素半径（0–200 步进 2，预设 0/4/8/12/16/24/32/48）。
- 画板：编辑画板宽 × 高（像素 + 预设 1920×1080、2560×1440、3840×2160、2480×3508 A4@300dpi）。
- 存储：截图保存目录（显示路径 / 更改… / 在 Finder 中显示）；**更改后要重启才生效**，更改时会把现有文件复制过去。
- 界面：`始终在 Dock 显示`、`历史栏位置`（左 / 右，默认右）、标注颜色、选区 / 裁剪框颜色。

**识字与翻译**

- Base URL、API Key（存钥匙串）、模型名、`测试连接`（翻译 "Hello"）。三项都填才启用大模型，否则回退系统本地翻译。

**关于与更新**

- 版本与构建号、GitHub / 官网链接、`自动检查更新` 开关、`检查更新` 按钮、发现新版时的 `安装并重启`。

打开设置窗口时会临时切到 `.regular`，关闭时重新评估激活策略。

## 12. 偏好键一览（UserDefaults，除特别说明）

`alwaysInDock`（默认 true）、`historySide`（left/right，**默认 right**）、`annotationColor`、`selectionColor`、`recentColors`（数组，最多 10 个 [r,g,b,a]）、`copyAfterCapture`（默认 false）、`smartCapture`（默认 true）、`roundedCapture`（默认 false）、`captureRadius`（默认 12）、`captureKeyCode`（默认 0 = A）、`captureModifiers`（Carbon 掩码，⌘256 ⇧512 ⌥2048 ⌃4096，默认 4096|2048）、`captureKeyLabel`、`imageFormat`（默认 png）、`boardWidth` / `boardHeight`（默认 1920 / 1080）、`historyLimit`（默认 50）、`historyDirectory`（缺省用默认目录）、`llmBaseURL`、`llmModel`、`numberDiameter`（上一个序号直径）、`automaticallyCheckUpdates`（默认 true）、`lastUpdateCheck`。

## 13. 已知注意事项 / 坑

- **自动模式拦截**：工具链里 `kill` / `pkill` / 重启正在运行的 Hoot 会被拦，需要用户自己退出并重开 `Hoot.app`。
- 画布正在编辑文字时，`CanvasView.acceptsFirstResponder` 必须为 false，否则点击会结束编辑；`controlTextDidEndEditing` 在拖动文字框期间要忽略（`editDrag != nil`）。
- 文字框拖动结束后只有在输入框**已失去焦点**时才重新聚焦，否则会误结束编辑。
- NSView 上的 `copy()` 会和 `NSObject.copy` 冲突，画布里用 `@objc(copy:)` + 不同的 Swift 方法名。
- 画布 `Handle.moves*` 必须是 public（文字缩放用到）。
- 编辑窗口一个截图开一个（`EditorWindowController`），“浏览”状态每个窗口各自独立。
- 内存：空闲约 100–300MB；缩略图和图片都有缓存上限。
- **没有做过自动化 UI 冒烟测试**：所有交互行为目前只靠编译 + ShotPadCore 单元测试 + 用户手工测试。改 UI 时请格外小心键盘、光标、手势这类看不见的逻辑。
- 旧的 `ShotPad.app` 可能还留在项目目录里（旧名字），可以手动删除；现在的产物是 `Hoot.app`。
- **版本号只在仓库根目录 `VERSION` 里写**（第 1 行 `X.Y.Z`，第 2 行 build 号）。`scripts/bundle.sh` 与 `landing/build.mjs` 都从它读取；落地页 `index.html` 只写 `{{VERSION}}` 占位符。漏改会让 `UpdateManager` 认为「已是最新」，自动更新**静默失效**。
- **自绘标题栏不是 `NSToolbar`**：第一版用默认 `NSToolbar` 高度和控件边框就偏离设计稿，第二版改成 70pt 自定义头部 + 原生红黄绿 + 标题栏 accessory 留位。别再退回 `NSToolbar`。
- **`EditorStyle` 之外不要散写尺寸**：侧栏 224 / 检查器 228 / 底栏 36 是常量；标题栏与下方栏的垂直分隔线依赖它们对齐。

- “浏览”：按修改时间排序、子文件夹选项、RAW/PDF、GIF 动画。
- 产品叙事：Hoot = “你 Mac 上看图、截图、录屏的小助手”，主线是 **看 → 改 → 存 → 传**。


## v0.2 设置与更新

- 设置左侧分为 **通用 / 识字与翻译 / 关于与更新**，原有设置全部保留。
- 每次打开设置，在当前画板窗口中心定位，限制在该窗口所在屏幕的可见区域；无画板时按鼠标所在显示器居中。
- 关于页显示版本和构建号、GitHub 和官网。
- GitHub Releases 为更新源；默认自动每日检查，下载与安装重启前明确提示。
- 安装包需通过 SHA-256、应用标识、版本、最低系统版本和原 Apple Team 签名校验，不能仅凭下载链接执行。
- 安装前完整写入全部画板草稿；失败则停止更新。独立安装脚本等待旧进程退出，在同目录替换并保留前版备份，随后自动打开 Hoot。
- 自动更新不会固定对象；新进程恢复对象及撤销/重做。实际安装目录不可写时显示错误，不自动提权。


## v0.2.1 智能截图与圆角

- 启动预热并缓存 ScreenCaptureKit 显示器信息；多屏抓图并发，显示器变化或缓存失效时刷新并重试一次；准备中禁止重复触发。
- 候选窗口按前后顺序命中，包含 Hoot 自身、普通窗口、对话框、工具面板和弹出层。
- Hoot 自身的控件边界在遮罩出现前从本进程公开辅助功能视图生成快照，不要求访问其他 App。
- 第三方 App：已授权辅助功能时，在后台查询鼠标下控件与父级的坐标边界；查询有短超时、去抖和旧结果丢弃，不在主线程阻塞等待。只读取位置、尺寸、父级，不读取文字或字段值。
- 本机 Vision 矩形检测为补充 / 无权限兜底，后台处理冻结截图。控件 / 面板 / 窗口按小到大排序，滚轮或 Tab 切换，Shift+Tab 反向；回车接受当前范围。不能保证自绘内容都有独立模块边界，始终保留拖动框选。
- 截图设置提供“智能识别窗口内部模块”、辅助功能授权入口、“截图圆角”、像素半径及预设。默认圆角关闭、半径 12px；0 为直角；PNG 保留透明角，不支持透明的历史格式继续垫白底。
- 圆角只应用于最终截图，遮罩预览同步显示圆角；没有修改画板、标注矩形的圆角设置。
