# Hoot 原生界面改造与功能核对

核对基线：`3507506` 中的 `docs/FEATURES.md`，功能代码基线为 `74f6e3d`。

## 改造范围

- 固定 70 点标题栏：文档信息、撤销/重做、识别、翻译与方向、复制、系统分享、导出、检查器开关。
- 分组标注栏：保留原有 12 个工具，补充已有“无工具/手形”状态的显式入口；窄窗口用更多菜单容纳低频工具。
- 历史侧栏：按日期分组，增加搜索、名称与时间，收紧缩略图和新建入口；继续支持历史栏放左或放右。
- 新建画板和截图各有独立的一键入口，保持原来的动作与存储流程。
- 右侧检查器承接原选项栏中的颜色、线宽/强度、字号和选区颜色。
- 固定常用色常驻；完整取色器、吸管和全部最近颜色收进“更多颜色”。最近颜色仍使用原有最多 10 色的持久化和去重规则，支持透明度的系统取色器仍可用。
- 常用字号下拉与步进器保留；50% / 100% / 150% 快捷缩放放在底栏，完整缩放菜单保留。
- 状态反馈改为短时浮层，画布使用更浅的背景和更轻的投影。

## 设计稿一致性修正

第一版使用默认 NSToolbar，标题栏高度和控件边框偏离稿件，并遗漏稿件中的完整属性栏。第二版修正：

- 自定义 70 点窗口头部，保留 AppKit 原生红黄绿按钮、窗口缩放、拖动；统一无边框图标与蓝色分体导出按钮。系统标题栏容器保留，使用公开标题栏 accessory API 留出空间。
- 检查器宽 228 点，按稿恢复颜色、描边、三种填充、不透明度、圆角、阴影、尺寸与位置、比例锁和排列分节。
- 填充、透明度、圆角、阴影和置顶/置底均连接真实渲染与撤销，PNG 导出包含效果。新增模型默认值为无填充、100% 不透明、0 圆角、无阴影，保持旧图形默认效果；不修改原有颜色偏好。
- W/H/X/Y 支持输入；浮动块和标注使用各自原模型更新。原鼠标手柄缩放方法不改。移动文字不新增换行宽度，移动水平线不改变倾斜角度。
- Shift 约束仅增加到新绘制矩形/椭圆，保持原拖动与文字交互。
- 980 点窄窗口收起识字/翻译的文字标签，动作与辅助功能标签保留。
- 不改保存/删除策略、默认 100% 缩放、真实历史文件命名、应用身份及用户设置。标题和侧栏短名仅去掉重复显示的时间后缀。

| 快捷操作条、原位预览、点击消失、复制/OCR/翻译/编辑/钉住 | QuickBar 与对应 AppDelegate 回调未修改。 |
| 画板、真实历史文件、各格式编码、命名、复制目录、剪贴板 | Board、HistoryStore、ImageFormat、Support 未修改。 |
| 工具再次点击取消、初始无工具、手形平移 | 原选择逻辑移入 chooseTool；切工具前仍完成文字编辑。 |
| 100% 的物理像素语义、缩放锚点、捏合、原缩放范围、适应窗口 | CanvasView 原缩放计算、范围与坐标算法保持原样；增加 zoomFitted 标记供菜单显示。打开历史仍为 100%。 |
| 选区抬起/移动/拉伸、浮动块定位线、确认/取消/图外扩展 | 对应鼠标和按键优先级与 Patch 处理保留；新增检查器尺寸编辑，不替换原拖动逻辑。 |
| 绘制后选中、同类工具才能再编辑、改色/线宽/字号 | 保留原 CanvasView 选择、命中与 styleChanged 流程；检查器绑定同一模型属性。 |
| 文字框拖动/缩放/换行/确认、双击重编、焦点保护 | CanvasView 的所有文字编辑方法、acceptsFirstResponder、EditDrag 处理未修改。 |
| Delete/Esc/方向键/Shift 微调/⌘X/C/V/A/Z/缩放 | CanvasView 原按键分支不变。新增搜索框输入时让原生文本框处理自己的编辑快捷键，避免把粘贴误送到画布。 |
| 光标与右键剪切/复制/粘贴 | 原 cursor、hit handle、menu(for:) 方法未修改；Core 命中增加有填充/圆角图形的分支，旧默认分支保留。 |
| 本地 Vision OCR、大模型优先/本地兜底翻译、浮动块不烘焙 | ResultWindow、TextTools、TextRecognizer、LLMTranslator 与 EditorModel 处理方法未修改。 |
| 翻译方向 | 继续独立选择并保存到同一 targetChinese 属性；选择方向不启动翻译。 |
| 钉住窗口与快捷键 | PinWindow 与原相关回调未修改。 |
| 历史删除/自动保留、缓存、存储格式、旧索引兼容 | HistoryStore 未修改。 |
| 切换浏览保留编辑状态、每窗口浏览独立 | 继续使用 StateObject BrowseModel 与保留画布的 ZStack；BrowseView 继续保留该行为。 |
| 浏览分组、文件夹拖入、目录监听、排序、EXIF、大图/网格、所有浏览键盘规则 | BrowseStore、ImageLoader 与浏览模型操作未修改；BrowseView 只调整布局与翻页点击区域。 |
| 从浏览送编辑不改原图、不套画板 | 原 editFromBrowse 动作保留。 |
| 所有设置项、偏好键、最近色和快捷键持久化 | SettingsView、AppSettings 未修改。 |
