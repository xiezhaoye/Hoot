# v0.2.1 截图与界面细化

## 修改

右侧历史栏与标题栏右组统一为 224pt；左侧历史栏时保留检查器 228pt。设置导航使用相同图标容器、18pt 最大图形尺寸、固定行高和文字起点，隐藏非选中键盘焦点装饰。

截图预热和缓存显示器信息，并行抓取各显示器，保持原生像素尺寸。前台窗口列表不再排除自己，也不再只接受 layer 0。控件识别异步加入，先展示窗口候选，候选到达后细化；手动滚轮 / Tab 选择不被迟到结果覆盖。

圆角半径使用图像像素，在截图裁出后裁切透明圆角；JPG 等格式按原格式编码逻辑垫白底。

## 验收

最终真实项目 55 项测试全部通过（包含真实更新包签名验证），release 构建与原开发者签名严格验证通过，版本 0.2.1 / build 3。

- 核心回归包含多屏坐标、候选去重、父子层级、遮挡边界、圆角透明像素与尺寸、实际 Vision 合成面板识别；保留此前全部编辑与更新回归。
- 独立 App 验证右侧分隔线、设置菜单选中 / 未选中样式、圆角开关与参数展开。
- 独立 App 使用合成冻结画面验证 96×40 控件 → 父面板的 Tab 切换、回车输出 PNG 和透明通道，避免给临时 App 新增录屏 / 辅助功能权限。
- 未终止用户正在运行的正式 Hoot，未代替用户授予辅助功能权限。真实第三方控件识别细度及实际冷 / 热截图耗时尚需在正式 App 获得权限后验收；不宣称所有自绘网页模块都可精确识别，也没有虚构加速百分比。
