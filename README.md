# ShotPad

macOS 截图 + 编辑工具（Swift 原生）。常驻菜单栏。

## 功能（第一、二期）
- 区域截图，悬停自动识别窗口并吸附，多显示器、Retina 像素精确；快捷键 `⌃⌥A`
- 编辑窗口：选区、矩形、圆圈、直线、箭头、画笔、荧光笔、马赛克、模糊、文字、序号、裁剪、撤销/重做
- **局部覆盖移动**：选区工具框选一块 → `⌘C` → `⌘V`，在光标处出现浮动块；拖动移动，拖 8 个手柄拉伸（按像素放大，空白块拉伸即铺满更大范围），回车确认、Esc 取消、方向键微调。直接拖动选区内部也会复制一份浮动块，原位置保留。
- 历史记录：本地保留最近 N 张（菜单可选 20/50/100/200），编辑窗口右侧缩略图，点击切换，编辑后自动写回
- 识别文字（Vision，中英文）；翻译（系统 Translation 框架，离线，原位覆盖译文，`⌘Z` 还原）
- 贴图：编辑窗口「贴图」或 `⌃⌥P` 贴剪贴板图片；拖动、滚轮缩放、右键透明度、双击/Esc 关闭
- 未做：滚动长截图（第三期）

## 构建
```bash
./scripts/bundle.sh   # 编译、生成并签名 ShotPad.app
swift test            # 核心逻辑测试
```
签名用本机 Apple Development 证书（可用环境变量 `SHOTPAD_IDENTITY` 覆盖），这样重新编译后「屏幕录制」授权不会失效。
首次运行在 系统设置 → 隐私与安全性 → 屏幕录制 中允许 ShotPad，然后重启应用。

## 结构
- `Sources/ShotPadCore`：渲染、浮动块/拉伸、撤销、历史存储、OCR（可测试，无界面）
- `Sources/ShotPad`：菜单栏应用、截图覆盖层、画布、SwiftUI 工具栏、贴图
- 历史数据：`~/Library/Application Support/ShotPad/History`
