想截哪里，就截哪里。

颜色 · 线宽 · 填充 · 透明度 · 圆角 · 阴影

用 ⌘S 固定全部对象并保存，也可以复制、系统分享或钉在桌面。固定后仍能撤销，重新调整对象；编辑草稿留在本地，重启后继续。

文件夹里的图，轻松翻。

本地文件夹按分组整理，大图与缩略图网格自由切换。点击画面左右区域或用方向键翻页，选中图片即可送入编辑，原文件保持完整。

用 Apple Vision 在本机识别中英文。需要翻译时，可接入自己的大模型服务；未配置或请求失败时，回退到系统本地翻译。

为什么做 Hoot

“想把 Windows 上用 PicPick
截图和编辑的顺手体验，带到 Mac。”

这是 Hoot 的起点。用 Swift 和 macOS 原生框架，从截图、看图和编辑这些每天都会做的小事开始，一点点打磨自己的答案。

xiezhaoye ↗Hoot 作者

灵感来自 PicPick。Hoot 是独立开发的应用，非 PicPick 官方 macOS 版本。

开始之前

你可能想知道。

Hoot 免费吗？

免费使用，并以 MIT 协议开源。你可以查看、修改和分发代码，具体条款见 MIT License。

需要什么系统？首次如何打开？

当前预览版支持 macOS 15 及以上的 Apple Silicon Mac。下载 ZIP 后解压，将 Hoot.app 拖入“应用程序”。安装包尚未经 Apple 公证；如果系统提示无法验证开发者，可确认来源后在“系统设置 → 隐私与安全性”中选择“仍要打开”。

截图为什么需要系统授权？

macOS 要求截图应用获取屏幕录制权限。首次使用时，请按提示在“系统设置 → 隐私与安全性 → 屏幕与系统音频录制”中允许 Hoot，然后重新打开应用。

为什么有些模块不能自动识别？

Hoot 结合控件边界与本机矩形识别来生成选区。更精确地识别其他 App 的控件，需要在“设置 → 通用 → 截图”中授权辅助功能。部分网页和自绘界面不提供完整边界，仍可拖动框选；滚轮或 Tab 可以切换更大的范围。

粘贴后还要按回车确认吗？

不需要。每次粘贴都是独立可编辑区块，之前粘贴的内容也能重新选中移动、缩放。“固定全部”（⇧⌘F）合并所有区块和标注；⌘S 合并并保存文件，⌘Z 可以撤销固定。第一次保存会让你选择 PNG 文件路径。

更新后能继续编辑吗？

设置中的“关于与更新”可检查新版，默认每日自动检查，安装重启前会提示。Hoot 保存全部画板的可编辑对象和撤销记录，重启后恢复现场。旧版本自动安装可能无法完成，请先手动下载并替换为 {{VERSION}}，之后可使用内置更新。

图片和识别的文字会上传吗？

截图历史保存在本地，OCR 使用本机 Apple Vision。启用你自己配置的大模型翻译时，识别后的文字会发送到该接口；API Key 存在 macOS 钥匙串中。系统本地翻译不需要该接口。

支持长截图和录屏吗？

当前版本专注截图、图片浏览与编辑，滚动长截图、录屏和视频剪辑尚未实现。你可以在 GitHub 提出需求或参与开发。
